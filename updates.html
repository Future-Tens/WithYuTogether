Version 1.2.1 Latest

Released: 2026/03/21

真實之眼與休憩的回響

👣 角色覺醒

幻影行者：全場唯一真預言家

「他的預知未來，才是真正的預知未來。」

現在，幻影行者的預知能力更進一步。除了看清前方的路徑，他甚至能洞察路盡頭的怪物種類以及可能獲得的掉落物。深淵的祕密在他眼中無所遁形。

⚔️ 系統與裝備升級

  • 武庫擴充：新增了部分物品與裝備。面對深淵，你現在擁有更多翻盤的手段。
  • 清晰決策：我們現在可以直接知道附上屬性詳細標註。資訊不對稱的時代結束了，請更好的做抉擇吧！

⚙️ 系統改善與調整

「皮繃緊了！現在冒險者在面對深淵的危脅無法再自由自在。」

  • 只有在休息處才有辦法分配能力值、強化靈魂。
  • 安全感正在消失：原有的 /分配屬性 指令現已停用，將於 v1.3.0 正式移除。

📊 戰鬥演算修正

  • | 魔法職業：修正了基礎傷害錯誤選用力量（STR）而非智力（INT）計算的問題。
  • | 混傷職業：修正基礎傷害係數，當前傷害公式已同步為 (STR + INT) × 0.8。

Version 1.2.0

Released: 2026/03/20

命運的波貝與深淵貿易

🎭 職業新增與平衡

新增職業：波貝 (Bober)

「這隻波貝將會改變生態(?」

  • 高幸運屬性，被動「自然之力」：消耗品回血 1.2 倍。
  • 副作用：看不懂中文... 可能在道路的抉擇稍有困難。
  • 破壁者：真的太破格了！削弱爆擊機率 (25% -> 15%) 及碎骨額外爆傷 (50% -> 35%)。
  • 求道者：神愛世人！修正了求道者升等時能力值異常低落的問題。
  • 血色祭司：血色祭司只剩一攤血，我們決定將他的「貧血體質」移除，增加生存力。
  • 幻影行者：修改探尋路線計算公式，現在幻影行者看得更清楚了。

⚙️ 系統改善

新增經濟與裝備系統，讓探險更有策略感！

  • 商人：在深淵與死神交易。消耗品價格隨關卡推進變貴。
  • 裝備：裝備正式實裝，有些強大神兵可是打不到的喔！
  • 物品價值：「深淵中所有物品都有價值啦！除了你的命！」

📊 數值演算優化 (LUCKY!)

// 新增 LUK (幸運) 影響爆擊機率與傷害
// 1 點 LUK (幸運) 相當於 0.4% 爆擊率和 0.2% 爆擊傷害
Crit Chance = (job_config.crit_chance + (LUK / 250))
Crit Mult = 1 + job_config.crit_mult + (LUK / 500)

// 傷害公式：最終傷害 = 基本傷害(稍有浮動) + 額外傷害(不觸發爆擊)

🔧 修復項目

  • | 修復創建角色按「重設點數」導致初始點數異常
  • | 修復偶爾發生的資料回溯 (Rollback) 問題
