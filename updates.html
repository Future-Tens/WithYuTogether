Version 1.3.0 Latest

Released: 2026/03/24

來自深淵的惡意，現在開始步步為營...

🧠 壓力系統 (Stress System)

深淵不再只是肉體的磨難，更會摧毀你的意志。每 1 點壓力將使你額外承受 1% 的傷害。

// 壓力產生源

受傷: +2 (每次受擊)
關卡推進: +4 (每 20 關成長一倍)

// 壓力上限與緩解

最高上限: 200 (2倍受傷)
減壓手段: 利用特定消耗品

⚖️ 生存機制全面改組

「深淵的利爪變得更加鋒利，敏捷不再是萬能的避風港。」

全職業減傷係數下修

  • 破壁者: 3.5 → 4 點敏捷/-1傷
  • 幻影行者、波貝: 3 → 4.5 點敏捷/-1傷
  • 血色祭司: 4 (維持不變)
  • 求道者: 3.5 (維持不變)

針對預言家的「惡意」

「既然你能預知未來，那我也更有機會找到你的弱點。」

  • 幻影行者：最大生命修正 (-15 → -20)，當前基準為 30。
  • 屬性重配：力量 (10→14), 敏捷 (22→18), 幸運 (10→15)。

🧩 數據驅動優化

全新的經驗值成長曲線

EXP_Req = LVL * 50(LVL * 0.01)
  • 狀態欄進化：屬性欄位現在標註為 主要屬性 (+ 裝備屬性加總)。

Version 1.2.1

Released: 2026/03/21

真實之眼與休憩的回響

👣 角色覺醒：全場唯一真預言家

「他的預知未來，才是真正的預知未來。」

幻影行者的預知能力現在能透視路徑盡頭的怪物種類以及可能的掉落物，真正的先知無所畏懼。

⚔️ 系統與裝備升級

  • 新增大量物品與裝備，應對深淵更有利。
  • 清晰決策：獲得裝備時直接標註詳細屬性資訊，不再盲目抉擇。

⚖️ 系統調整

「現在只有在休憩處才有辦法分配點數，你無法再隨心所欲地在戰鬥前強化靈魂。」

※ /分配屬性 指令已停用，將於 v1.3.0 正式移除。

Version 1.2.0

Released: 2026/03/20

命運的波貝與深淵貿易

🎭 職業與平衡

  • 新增職業「波貝」：高幸運、高回復（1.2倍）。副作用：看不懂中文，抉擇困難。
  • 破壁者削弱：爆擊機率 (25%->15%)、額外爆傷 (50%->35%)。
  • 修正求道者：修復升等能力異常低落的問題。
  • 血色祭司調整：移除貧血體質，強化生存能力。

📊 數值演算更新

Crit_Chance = (job_crit + (LUK / 250))
Crit_Mult = 1 + job_crit_mult + (LUK / 500)
最終傷害 = 基本傷害(浮動) + 額外傷害(不觸發爆擊)
商人系統：擊敗怪物獲取金幣，在休息點購買商店神裝。
修正項目：解決重設點數異常、修復隨機資料回溯問題。
